# Alien Invaders

A Python Turtle-based space shooter game where the player controls a spaceship, shoots incoming aliens, earns points, progresses through levels, and battles powerful bosses. The game includes moving stars, a scoring and lives system, increasing difficulty, boss battles, lasers, explosions, and a pause feature.


## How to Run

1. Make sure Python is installed on your computer.
2. Make sure the Python `turtle`, `random`, and `time` modules are available.
3. Open the project folder.
4. Run the Python file containing the Alien Invaders game.
5. The game window will open.
6. Press **Enter** to start the game.


## Controls

- **Left Arrow** — Move the spaceship left.
- **Right Arrow** — Move the spaceship right.
- **Space** — Fire a bullet.
- **P** — Pause or resume the game.
- **Enter** — Start or restart the game.


## Features

- Space-themed game screen with moving stars.
- Player-controlled spaceship.
- Left and right movement controls.
- Bullet shooting system.
- Multiple alien enemies with different colors.
- Score and lives system.
- Increasing difficulty as the player progresses.
- New levels every 10 points.
- Alien speed increases with each level.
- Boss battles on every fifth level.
- Boss health bar.
- Boss movement across the screen.
- Boss laser attacks.
- Boss defeat animation and fireworks.
- Explosion effects when enemies are hit.
- Pause and resume functionality.
- Game-over and restart screens.
